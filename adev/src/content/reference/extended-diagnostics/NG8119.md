# Templates should not reference deprecated symbols.

This diagnostic detects usages of symbols marked with the [`@deprecated`](https://jsdoc.app/tags-deprecated) JSDoc tag inside Angular templates.

```angular-ts
import {Component, Input} from '@angular/core';

@Component({
  selector: 'profile-card',
  template: `<button (click)="open()">Open</button>`,
})
class ProfileCardComponent {
  /** @deprecated Use `userId` instead. */
  @Input() id?: string;

  /** @deprecated Use `openProfile()` instead. */
  open() {}
}

@Component({
  imports: [ProfileCardComponent],
  template: `<profile-card [id]="value" />`,
})
class HostComponent {
  value = '1';
}
```

In the example above, the binding `[id]="value"` targets a deprecated input and the diagnostic
will report it. Usages of deprecated components, directives, pipes, inputs, outputs, and
properties or methods accessed in template expressions are all detected.

## What's wrong with that?

Deprecated symbols are still functional, but they are scheduled for removal and usually have a
recommended replacement. Continuing to use them in templates spreads soon-to-be removed code
across the application, makes future upgrades more painful, and hides important guidance from
developers reading the template.

## What should I do instead?

Switch to the recommended replacement documented in the symbol's `@deprecated` tag. For
example, replace deprecated inputs/outputs with their newer counterparts and update template
expressions to call non-deprecated methods or read non-deprecated properties.

```angular-ts
@Component({
  imports: [ProfileCardComponent],
  template: `<profile-card [userId]="value" />`,
})
class HostComponent {
  value = '1';
}
```

## Configuration requirements

[`strictTemplates`](/tools/cli/template-typecheck#strict-mode) must be enabled for any extended diagnostic to emit.
`deprecatedSymbolInTemplate` has no additional requirements beyond `strictTemplates`.

## What if I can't avoid this?

This diagnostic can be disabled by editing the project's `tsconfig.json` file:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "deprecatedSymbolInTemplate": "suppress"
      }
    }
  }
}
```

See [extended diagnostic configuration](/extended-diagnostics#configuration) for more info.
